# xbox-sales-dashboard
Este projeto transforma dados brutos de assinaturas do Xbox Game Pass em um "dashboard interativo no Excel"', permitindo análise clara e visual do desempenho de vendas.
# Dashboard de Vendas - Xbox Game Pass


## 🚀 Funcionalidades
- Visualização do faturamento por tipo de plano (Core, Standard, Ultimate).
- Análise por tipo de assinatura (Mensal, Trimestral, Anual).
- Indicadores de auto-renovação.
- Vendas de passes adicionais (EA Play, Minecraft).
- Gráficos dinâmicos e indicadores principais.

---

## 📂 Estrutura
- **Bases**: dados brutos de assinantes.
- **Cálculos**: tabelas dinâmicas respondendo perguntas de negócio.
- **Dashboard**: visualização consolidada e interativa.

---

## 📸 Capturas de Tela
Disponíveis na pasta `/images`:
- `dashboard.png` → visão geral do dashboard.
- `planos.png` → análise por tipo de plano.
- `passes.png` → vendas de passes adicionais.

---

## 🛠️ Como Usar
1. Baixe o arquivo `Xbox_Sales_Dashboard.xlsx`.
2. Abra no Excel.
3. Navegue pelas abas e explore os gráficos dinâmicos.
4. Use filtros para personalizar a análise.
